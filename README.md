# 💳 Credit Card Fraud Detection

## 🚀 Overview
This project builds machine learning models to detect fraudulent transactions in highly imbalanced datasets.

## 🎯 Objectives
- Identify fraudulent transactions
- Handle imbalanced data
- Evaluate model performance using precision, recall, and ROC-AUC

## 🛠️ Tools & Technologies
- Python
- Scikit-learn
- Pandas, NumPy

## 📈 Key Insights
- Class imbalance significantly affects model performance
- Precision and recall are critical metrics
- Effective fraud detection requires careful tuning
